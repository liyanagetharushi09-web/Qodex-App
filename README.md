# QODEX - Quiz & Riddle App
================================

## Description
QODEX is a fun and interactive mobile quiz application developed as part of the CO1007 Computing Challenge module at the University of Lancashire. 
It combines multiple-choice quizzes and riddles with a real-time leaderboard to create an engaging, gamified learning experience. 
The app was built using Agile methodology with iterative development, Kanban workflow management, and continuous testing to ensure quality and usability.

## Features
- 🎮 Two modes: "Quick Quiz" (MCQs) and "Let's Start Your Journey" (Riddles)
- 📊 Real-time leaderboard for competitive play
- 🧩 Hint system to support problem-solving
- 🎨 User-friendly UI with consistent purple theme
- 🔗 Integration with Google Sheets for quiz data
- 🌐 Web API communication for riddles and scoring
- 📱 Cross-device compatibility (tested on Android and desktop preview)

## System Design
- **Frontend:** Built with Thunkable, providing intuitive navigation across Home, Quiz, Riddle, Score, and Leaderboard screens.
- **Backend:** Handles data storage, server communication, and logic. Fetches quiz questions from Google Sheets and riddles via API.
- **Architecture:** Client-server model separating presentation layer from business logic for maintainability and performance.

## Branding
- Logo: Futuristic robot mascot inside "QODEX" lettering
- Theme: Purple with neon highlights to symbolize creativity and intelligence
- Slogan: *"Quiz Your Way to Success"*
- Marketing: Poster, viral video, and social media campaigns (Instagram & YouTube)

## Testing
- Functional, usability, and compatibility testing performed iteratively
- Test cases included app launch, email validation, quiz flow, score calculation, and leaderboard updates
- User feedback sessions improved clarity, navigation, and overall experience

## Purpose
QODEX was designed to make learning enjoyable by blending education with gamification. 
It motivates users through competition, instant feedback, and replayability, encouraging continuous learning and skill development.
